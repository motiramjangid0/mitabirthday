FULL-SCREEN BIRTHDAY SURPRISE
Default PIN: 2001

Open index.html.

Change PIN: script.js -> const PIN='2001'
Change name/date/message: edit index.html
Add song: put MP3 at music/birthday.mp3
Add photo: put image in images/photo1.jpg, then replace the photo placeholder in index.html with:
<img src="images/photo1.jpg" style="width:100%;height:auto;display:block;border-radius:22px">

This version removes the narrow card. On mobile the whole browser screen is the birthday experience.

COUNTDOWN: Birthday is set to 10 September 2026 at 12:00 AM in script.js.
Before that date, correct PIN opens the countdown. On/after that date, the surprise opens automatically.
